# Customer Support Database - Installation

This repository contains the ClickOnce installation files for the Customer Support Centralised Database application.

## 🚀 Quick Install

**[Click here to install the application](https://richardloosemore.github.io/Customer-Support-Database-Installer/)**

Or use the direct installation link:
```
https://richardloosemore.github.io/Customer-Support-Database-Installer/Customer%20Support%20Centralised%20Database.application
```

## 📋 System Requirements

- **Operating System:** Windows 10 or later
- **.NET Framework:** 4.8.1 or later
- **Internet Connection:** Required for installation and automatic updates

## 🔄 Automatic Updates

The application is configured to check for updates automatically when you launch it. When a new version is available, you'll be prompted to update before the application starts.

## ⚙️ Installation Instructions

1. Click the installation link above
2. Click **Install** when prompted by ClickOnce
3. Accept the security prompt (the application is signed by Sheppee International LTD)
4. The application will download and install
5. A desktop shortcut will be created automatically

## 🔒 Security

This application requires Full Trust permissions to:
- Access local and network databases
- Read and write files
- Generate reports and documents
